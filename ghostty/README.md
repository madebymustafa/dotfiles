# Ghostty

GPU-accelerated terminal emulator. Config: `config`.

- catppuccin-mocha theme, JetBrains Mono at 19pt
- 80% background opacity with a 10px blur (matches WezTerm's transparency)
- Option mapped to Alt (needed for AeroSpace bindings)
- Non-native fullscreen so AeroSpace keeps managing windows
`shaders/` holds GLSL experiments; `ps.json` is saved palette data.
