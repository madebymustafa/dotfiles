# tmux

Terminal multiplexer. Config: `.tmux.conf`.

Theme: catppuccin. Plugins (managed by tpm): sensible, yank, resurrect,
continuum, thumbs, fzf, fzf-url, sessionx, floax, vim-tmux-navigator.

- `Ctrl+h/j/k/l` moves between tmux panes and neovim splits seamlessly
- sesh integration binds session pickers (see `sesh/`)
- `.tmux.reset.conf` is a minimal fallback config for debugging
Plugins live in `~/.tmux/plugins/` and are not tracked.
